Originally born and raised in the Midwest, Luther received a Bachelor of the Arts in Computer Science from Gustavus Adolphus College in Southern Minnesota. After that he moved to the expansive deserts of the American Southwest. In Arizona, Luther spent his career building web APIs and utilities for various industries in PHP and NodeJS. From there he migrated to Open Source DevOps tooling using Containers and Virtualization.

Luther works at Akamai on LKE Enterprise, the enterprise tier of the Linode Kubernetes Engine. Before Akamai he spent years in the Kubernetes space at Rancher Labs and SUSE working on the Multi-Cluster Management tool Rancher. As the Team Lead for Windows on Rancher he specialized in Kubernetes on alternative operating systems and architectures including Windows, arm64 and s390x. After Rancher he worked at Spectro Cloud on Cluster API providers for AWS and Azure. That included OIDC/IRSA support for self-managed clusters on AWS. Working in this unique space and working from home full time has made him a home lab aficionado and consumer of Proxmox VE.

ePHPm

ePHPm runs the same PHP app the same way from dev to prod as one Rust binary. It embeds real PHP through a custom SAPI. It bundles a web server with automatic TLS, an embedded SQLite-compatible database, a KV cache, a pooling SQL proxy and gossip clustering. A PHP app runs as a single process with no other services to operate.

ephemerd

ephemerd is ephemeral GitHub Actions runners in a single binary for every platform: containers on Linux, Hyper-V on Windows, VMs on macOS. Every job gets an isolated, disposable environment that is thrown away when the job finishes.

litewire

litewire speaks the MySQL, PostgreSQL and SQL Server wire protocols in front of SQLite. Point pdo_mysql at :3306 and an unmodified app runs on embedded SQLite. There’s no database server and no code changes. It is the database layer inside ePHPm.

shipmates

shipmates gives Claude Code subagents that remember. It provides role-specialized personas with persistent per-project memory. It also has a live lead-and-crew channel for dispatching work, steering an agent mid-task and approving actions with a human in the loop.

go-proxmox

go-proxmox is a Go client, with types and tests, for the Proxmox VE REST API. It started in 2021 as a side project for the home lab. It’s now used by projects like the Cluster API provider for Proxmox.
